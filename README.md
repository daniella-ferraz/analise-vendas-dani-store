# 📊 Dani Store - Análise de Vendas

## 📊 Dashboard

![Dashboard de Análise de Vendas](dashboard.png)

## 📌 Sobre o projeto

Este projeto apresenta uma análise de vendas da Dani Store, desenvolvida no Microsoft Excel com o objetivo de transformar dados de vendas em informações úteis para a tomada de decisões.

## 🛠️ Ferramentas utilizadas

- Microsoft Excel
- Tabelas e fórmulas
- Gráficos
- Dashboard
- Análise de dados

## 📈 Principais análises

- Faturamento total
- Faturamento por categoria
- Faturamento por cidade
- Produto com maior quantidade vendida
- Maior venda realizada
- Insights e recomendações para o negócio

## 💡 Principais insights

- O faturamento total analisado foi de *R$ 17.710,00*.
- Eletrônicos foi a categoria com maior faturamento, com *R$ 13.650,00*.
- *São Paulo* apresentou o maior faturamento, com R$ 12.360,00.
- *Caderno* foi o produto com maior quantidade vendida, com *20 unidades*.
- A maior venda analisada foi de um *Notebook, no valor de **R$ 6.000,00*.

## 🎯 Objetivo

Demonstrar a aplicação de conceitos de análise de dados utilizando Excel, apresentando informações de forma visual e facilitando a identificação de oportunidades para o negócio.
